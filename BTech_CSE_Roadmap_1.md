# BTech CSE Roadmap — 1st Sem se Job tak (3-5 Internships ke saath)

> Tum abhi: **1st Year, 1st Sem, 1 week ho gaya hai class start hue.**
> Goal: 2nd sem se hi internship-ready banna, 3-5 internships karna, final year me job.

---

## PHASE 0 — Ye 1st Sem me hi kar lo (Foundation)

Abhi ka goal sirf ek hai: **coding ki habit banao**, deep skill nahi chahiye abhi.

### Kya seekhna hai
1. **Ek programming language pakki karo** — Python ya C++ (recommend: **C++** agar DSA/placements ka plan hai, warna Python easy hai start ke liye)
2. **Basic programming concepts**: loops, arrays, functions, recursion, OOP basics
3. **Git & GitHub basics** — account bana lo, ek repo banake practice code push karna seekho
4. **Typing speed + terminal/command line comfort**

### Kya karna hai
- Roz **1-2 hours coding practice** — CodeChef/HackerRank/LeetCode (easy problems) pe 100+ basic problems solve karo
- College ke syllabus ko seriously lo — mostly Maths + Programming fundamentals hi hote hai 1st sem me, dono strong karo
- **LinkedIn profile bana lo** (abhi se, professional photo, headline: "CS Undergrad | Learning DSA & Web Dev")
- **GitHub profile setup karo**

### Target by end of 1st Sem
- 1 language me comfortable
- 100+ basic coding problems solved
- Git/GitHub ka basic use aata ho

---

## PHASE 1 — 2nd Semester (DSA Start + First Skill)

Ye sem se **serious DSA** start karo, kyuki internships (2nd year se) me DSA hi asli filter hota hai.

### Kya seekhna hai
1. **Data Structures**: Arrays, Strings, Linked List, Stacks, Queues
2. **Basic Algorithms**: Sorting, Searching, Time Complexity (Big O)
3. Ek **web dev basics** shuru karo parallel me (HTML, CSS, JS basics) — ye tumhe jaldi ek "showable project" banane me help karega

### Kya karna hai
- DSA: **LeetCode/GFG** pe daily 2-3 problems (Easy → Medium shift dheere dheere)
- Ek **mini project** banao (to-do list app, calculator, portfolio website) — HTML/CSS/JS se
- **Resume ka Version 1 bana lo** (even if khaali sa lage — projects fill karte jaana)
- DSA sheets follow karo: **Striver's SDE Sheet** ya **Love Babbar 450**

### Target by end of 2nd Sem
- 250+ DSA problems (cumulative)
- 1-2 small projects on GitHub
- Resume v1 ready
- Basic web dev (HTML/CSS/JS) ka comfort

---

## PHASE 2 — 3rd Semester (Internship Hunt #1 Starts)

Ab tum **1st internship ke liye apply karna** start karoge — chhoti/unpaid/remote bhi chalegi, bas experience chahiye.

### Kya seekhna hai
1. DSA continue: **Trees, Graphs, Recursion, Backtracking**
2. Ek **tech stack** pick karo aur usme depth jao:
   - Web Dev: React + Node.js (MERN), ya
   - App Dev: Flutter/Android, ya
   - Data/AI: Python + basic ML
3. **DBMS basics** (SQL queries, normalization)

### Kya karna hai
- **2-3 solid projects** banao is stack me (ek full-stack project zaroor ho, GitHub pe achhe README ke saath)
- **Apply karna start karo**: Internshala, LinkedIn, Unstop, college placement cell, cold DMs on LinkedIn/Twitter to startups
- Local hackathons/college hackathons me participate karo — networking + resume booster
- Resume v2 (projects ke sath update)

### Target by end of 3rd Sem
- **Internship #1 lag jaana chahiye** (chhota bhi chalega — 1-2 month, remote, unpaid bhi)
- 400+ DSA problems
- 1 tech stack me solid grip

---

## PHASE 3 — 4th Semester (Internship #2 + DBMS/OS/CN)

### Kya seekhna hai
1. **Core CS Subjects** (college me aayenge, seriously padhna — interviews me poochte hai):
   - Operating Systems
   - Computer Networks
   - DBMS (advanced)
2. DSA: **Dynamic Programming, Greedy, Graphs advanced**
3. System Design basics (LLD — low level design) shuru kar sakte ho halka

### Kya karna hai
- **Internship #2 ke liye apply** — is baar thoda better company target karo kyuki ab 1 experience + projects hai
- Open source contribution try karo (GitHub pe beginner-friendly issues)
- LinkedIn pe active raho — apne projects/internship experience post karo (visibility badhegi)
- Mock interviews start karo (peer group ke saath)

### Target by end of 4th Sem
- **Internship #2 done**
- Core subjects (OS, CN, DBMS) ka strong conceptual base
- 600+ DSA problems
- LinkedIn pe kuch network ban chuka ho

---

## PHASE 4 — 5th Semester (Internship #3 — Paid/Better Company Target)

Ab tum "junior developer" jaisa dikhna chahiye resume pe.

### Kya seekhna hai
1. DSA: Advanced patterns, **company-specific question sets** (companies jo tum target kar rahe unke previous questions)
2. System Design (basic HLD bhi shuru karo)
3. Apne stack me **ek advanced project** — real-world problem solve karne wala (deployment bhi seekho: AWS/Vercel/Render)

### Kya karna hai
- **Internship #3 apply** — is baar paid + bada company/startup target karo
- Resume v3 — ATS-friendly banao, quantify karo achievements ("improved load time by 30%" type)
- LeetCode contests (weekly) participate karo — rating banega, resume me daal sakte ho
- Referral maango seniors/LinkedIn connections se

### Target by end of 5th Sem
- **Internship #3 (ideally paid) done**
- Deployment/DevOps basics
- Strong resume with 3 internships + 4-5 projects

---

## PHASE 5 — 6th Semester (Internship #4-5 + Placement Prep Start)

### Kya seekhna hai
1. **Full interview prep**: DSA revision, System Design (HLD+LLD), CS fundamentals revision
2. Behavioral/HR round prep
3. Company-specific prep jaha tum apply karoge (off-campus + on-campus dono)

### Kya karna hai
- **Internship #4/#5** — ab try karo ki koi bada/product-based company ho, ya wahi company jaha PPO (pre-placement offer) ki possibility ho
- **On-campus placement drives** start ho jaate hai usually 6th-7th sem me — inke liye tayar raho
- Mock interviews weekly (peer/senior/platforms jaise Pramp)
- Apna resume + LinkedIn recruiters ko dikhne layak polish karo

### Target by end of 6th Sem
- **3-5 internships complete ho chuke honge (target achieved!)**
- Placement-ready resume + strong DSA + System Design basics

---

## PHASE 6 — 7th-8th Semester (Job Hunt)

### Kya karna hai
- **On-campus placements** seriously do — company research karo, unke interview pattern samjho
- **Off-campus applications** parallel me continue rakho (LinkedIn, Naukri, company career pages, referrals)
- Agar koi internship company se **PPO (Pre-Placement Offer)** mila hai, use priority do
- Interview rounds: OA (online assessment) → Technical (DSA+CS fundamentals+project discussion) → HR

### Target
- **Job offer secured before/around final sem**

## Golden Rules (Har Semester Follow Karo)

1. **Consistency > Intensity** — roz 1-2 hours coding, saal bhar break mat lo
2. **Projects with GitHub + README** — sirf code nahi, achhe se document karo
3. **LinkedIn pe active raho** — recruiters wahi se dhundte hai
4. **Communication skills** bhi improve karo — English speaking, mock interviews
5. **Har internship ke baad resume update karo** — turant, delay mat karo
6. Har sem end me apna progress **review karo** — kya seekha, kaha weak ho, next sem ka plan adjust karo

---

*Bas itna yaad rakho: pehla internship sabse mushkil hota hai lena, uske baad flow ban jaata hai. Isliye 2nd-3rd sem me full effort second internship pe mat rakho — pehla internship (chhota bhi) jaldi lag jaye, wahi priority ho.*
