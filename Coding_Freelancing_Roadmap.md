# Coding Freelancing Roadmap (Sem 1 - Sem 2)

## Semester 1 — Coding Foundation

### Month 1: Web Basics
- HTML5 — structure, semantic tags, forms
- CSS3 — flexbox, grid, responsive design
- Practice: 5-6 chote static pages banao (landing page, portfolio page, resume page)
- Resource: CodeWithHarry, freeCodeCamp, MDN docs

### Month 2: JavaScript Fundamentals
- Variables, functions, loops, arrays, objects
- DOM manipulation, events
- Fetch API basics (data lena/dena)
- Practice: Calculator, To-Do list, Weather app (API use karke)

### Month 3: Git, GitHub aur Tools
- Git basics — commit, push, pull, branch
- GitHub pe apna code upload karna seekho (ye portfolio ka base hai)
- VS Code shortcuts aur extensions
- Chrome DevTools use karna seekho (debugging)

### Month 4: Frontend Framework
- React.js basics — components, props, state, hooks
- Practice: 2-3 React projects (movie search app, expense tracker)
- Tailwind CSS bhi seekh lo — jaldi aur professional UI banane mein help karega

### Month 5-6: Backend Basics
- Node.js + Express — server banana, routes, middleware
- Database — MongoDB (NoSQL, beginner-friendly) ya MySQL
- REST API banana seekho
- Practice: Full CRUD app (jaise blog app ya task manager with backend)

---

## Semester 2 — Advanced + Freelancing Start

### Month 7: Full-Stack Project + Portfolio
- MERN stack (MongoDB, Express, React, Node) mein 1-2 solid full-stack projects banao
- Authentication (login/signup) implement karo — clients isko bohot maangte hain
- Apna khud ka portfolio website banao aur deploy karo (Vercel/Netlify)

### Month 8: Deployment aur Real-World Skills
- Deployment seekho — Vercel, Netlify, Render, ya basic AWS/Hostinger
- API integration (payment gateway jaise Razorpay/Stripe, ya third-party APIs)
- Responsive design polish karo — mobile pe bhi perfect dikhna chahiye

### Month 9: Freelancing Platforms pe Start
- Fiverr aur Upwork profile banao — clear services list karo (e.g., "I will build responsive websites using React")
- Low pricing se start karo pehle 3-5 clients ke liye, reviews ke liye
- WordPress bhi seekh lo side mein — bohot clients isi mein kaam maangte hain (chota investment, bada return)

### Month 10: Client Handling aur Niche
- Ek niche pick karo: business websites, e-commerce stores, landing pages, ya web apps
- Client se requirements lena, scope define karna, deadline commit karna seekho
- Simple invoicing/contract templates use karo

### Month 11: Advanced Skills
- TypeScript seekho (React + TS combo bohot demand mein hai)
- Basic testing (Jest) aur clean code practices
- Performance optimization basics (loading speed, SEO basics for websites)

### Month 12: Scale Karna
- Rates badhao, repeat clients banao
- LinkedIn pe apna kaam share karo — recruiters aur clients dono dekhte hain
- Referral system banao — ek client se agla client milta hai

---

## Quick Tips
- Roz code likho, sirf videos mat dekho — "tutorial hell" se bacho
- GitHub profile active rakho, ye trust build karta hai
- Fiverr/Upwork pe pehle gig ke liye patience rakho, 1-2 mahine lag sakte hain
