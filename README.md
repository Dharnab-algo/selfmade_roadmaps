# ICPC + GSoC + Google SWE Roadmap 🚀

A structured, semester-wise roadmap for a CSE student aiming to:
- Compete in **ICPC** (regionals → world finals push)
- Get selected for **Google Summer of Code (GSoC)**
- Land a **Software Engineering internship**
- Get placed at **Google** as a Software Engineer

> Starting point: 1st semester CSE, prior experience in Python, learning C++ from scratch.

## ✅ How to use this repo

1. Read `00_Overview.md` first for the big picture.
2. Follow the year-wise files in order — each has a checklist you can track.
3. Copy `06_Weekly_Checklist.md` every week to log progress (or convert it into a Notion/Sheets tracker).
4. Update this repo as you progress — turn checkboxes into `[x]` as you complete them.

## ⚠️ Reality Check

This roadmap maximizes your chances — it doesn't guarantee outcomes.

- **ICPC World Finals** is extremely competitive; qualifying at the regional level is already a strong achievement.
- **GSoC** has a low selection rate; early community engagement matters more than the proposal alone.
- **Google hiring** is highly selective — this prep will make you competitive for Google *and* other top companies.

Progress > perfection. Consistency is the real edge here.
